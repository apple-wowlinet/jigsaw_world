# Puzzle 图片规范

本文档用于指导 JigsawWorld 拼图图片的选择、制作、审核和上传。目标是在拼图清晰度、游戏操作体验、页面展示效果和加载性能之间取得平衡。

## 1. 标准规格

新加入的 Puzzle 图片应优先遵循以下标准：

| 项目 | 建议 |
| --- | --- |
| 首选宽高比 | `3:2`，例如 `2048 × 1365` |
| 备选宽高比 | `4:3`，例如 `2048 × 1536` |
| 可接受比例范围 | 约 `1.25:1`～`1.6:1` |
| 最低尺寸 | 长边至少 `1200px` |
| 常规推荐尺寸 | 长边 `1600px`～`2048px` |
| 500 块拼图 | 长边建议接近 `2048px` |
| 首选格式 | WebP |
| 兼容格式 | JPEG |
| 建议文件大小 | `300KB`～`1.5MB`，尽量不超过 `2MB` |

如果只使用一套统一的上传标准，采用以下规格：

```text
尺寸：2048 × 1365
比例：3:2 横图
格式：WebP
文件大小：建议小于 1.5MB
构图：关键主体位于中央 70% 的安全区域
内容：避免大面积纯色、模糊或重复纹理区域
```

## 2. 宽高比选择

### 3:2（首选）

`3:2` 与站内列表卡片约 `1.55:1` 的展示比例接近，适合作为默认图片比例：

- 列表缩略图不会出现明显裁切。
- 在桌面横屏画布中可以有效利用空间。
- 适合风景、建筑、动物、城市和艺术等常见题材。
- 相比 `16:9` 不会过于扁长，拼块更容易观察和操作。

### 4:3（备选）

`4:3` 画面更加紧凑，适合主体集中或需要兼顾移动端展示的图片。使用该比例时，列表卡片可能对图片上下边缘进行少量裁切。

### 不推荐的比例

- 不建议将 `16:9` 作为默认规格。图片在手机画布中会显得较矮，拼块也容易集中在狭长区域。
- 不建议常规使用竖图。除非页面和游戏画布已针对竖向图片进行专门适配。
- 避免使用超过上述可接受范围的超宽图、全景图或过度狭长图片。

## 3. 不同拼块数量的尺寸建议

| 拼块数量 | 最低建议尺寸 | 理想尺寸 |
| ---: | --- | --- |
| 24～100 | `1200 × 800` | `1600 × 1067` |
| 120～300 | `1600 × 1067` | `2048 × 1365` |
| 500 | 长边至少 `1800px` | `2048 × 1365` 或 `2048 × 1536` |

低于最低建议尺寸的图片在高分辨率屏幕或高拼块数量下可能出现模糊、纹理缺失和拼块边缘不清晰的问题。

当前自定义图片上传流程会将图片最长边缩小到不超过 `2048px`。因此，通常没有必要上传远高于该尺寸的图片；过大的源文件会增加下载时间、图片解码耗时和显存占用。

## 4. 构图与裁切安全区

站内不同页面可能使用不同容器比例并通过 `object-cover` 展示图片，因此原图边缘可能被裁切。

对于 `3:2` 图片：

- 将人物面部、动物头部、建筑主体等关键内容放在中央约 `70%` 的宽度范围内。
- 不要将关键内容、文字或视觉焦点贴近左右边缘。
- 为主体周围保留适量背景，使图片在列表卡片和详情页中裁切后仍然完整。
- 游戏过程中会展示完整拼图内容，但目录缩略图和详情展示可能只显示图片中央区域。

## 5. 内容选择标准

适合制作拼图的图片应尽量满足以下条件：

- 全画面具有颜色、纹理、轮廓或明暗变化。
- 主体清晰，但不要只有一个孤立主体和大面积空白背景。
- 前景、中景和背景均有可识别的视觉元素。
- 图像清晰锐利、曝光正常、对比适中。
- 不同区域具有足够的颜色或形状差异，便于玩家判断拼块位置。
- 细节分布相对均衡，不要把所有有效信息集中在画面中央的小范围内。

应避免以下情况：

- 天空、海水、白墙、黑色背景等单一色块占据画面约 `25%` 以上。
- 大面积景深虚化、运动模糊或低清晰度区域。
- 高度重复且缺少定位特征的纹理，例如整片草地、沙地或规则砖墙。
- 严重过曝、欠曝、噪点或 JPEG 压缩伪影。
- 水印、版权标记、难以辨认的小字或贴近边缘的文字。
- AI 生成图片中明显的结构错误、重复物体或不连续纹理。

大面积相似纹理可以用于高难度 Puzzle，但应明确标记难度，避免将其作为新玩家的默认体验。

## 6. 文件处理建议

- 优先输出 WebP，在相近视觉质量下减少图片体积。
- JPEG 建议使用约 `85%`～`92%` 的质量设置。
- 上传前移除不必要的 EXIF 和其他元数据。
- 使用 sRGB 色彩空间，避免不同浏览器和设备出现明显色差。
- 不要为了减小文件体积过度压缩，应确保细小纹理和边缘保持清晰。
- 同一 Puzzle 的游戏图和缩略图应使用相同构图来源，避免玩家进入游戏后发现内容明显不同。

## 7. 发布前检查清单

发布 Puzzle 前确认：

- [ ] 图片比例处于 `1.25:1`～`1.6:1` 范围，优先使用 `3:2`。
- [ ] 长边至少 `1200px`，高拼块数量图片接近 `2048px`。
- [ ] 文件采用 WebP 或高质量 JPEG，大小尽量不超过 `2MB`。
- [ ] 关键主体处于中央 `70%` 安全区域。
- [ ] 缩略图裁切后仍能清楚表达主题。
- [ ] 图片清晰，无水印、明显噪点或压缩伪影。
- [ ] 没有不符合目标难度的大面积纯色、模糊或重复区域。
- [ ] 在桌面端和移动端分别检查列表、详情页和游戏画面。
- [ ] 图片版权和使用授权符合项目发布要求。
